Module 06: Prepare InPage Document

Learning Outcomes: After completion of this learning module, learners will be able to create new documents in InPage, insert images and objects, perform text/paragraph formatting, and print or export documents[cite: 10].

Learning Unit 1: Create a New Document in InPage

InPage: An advanced Urdu word processor that supports both Urdu and English typing, formatting, composing, and printing[cite: 10]. InPage documents are saved with the .INP extension[cite: 10].

Creating a New Document:

  • Go to File > New (Shortcut: Ctrl + N), define page dimensions (e.g., A4 size), margins, and click OK[cite: 10].
  • Keyboard Setup: Before typing Urdu, select the Phonetic Keyboard via Edit > Preferences > Keyboard Preferences and choose Phonetic[cite: 10].
  • Typing Rules: Use the Tab key instead of the spacebar for spacing between words[cite: 10]. Use the Enter key only when starting a new paragraph[cite: 10].

The Tool Box (Tools & Shortcuts):

  • Arrow Tool: Ctrl + 1 (Object modification)[cite: 10]
  • I-Beam Tool: Ctrl + 2 (Text typing and editing)[cite: 10]
  • Rotation Tool: Ctrl + 3[cite: 10]
  • Text Box / Title Text Box: Shift + F2 / Shift + F3[cite: 10]
  • Picture Box Tools (Rectangular/Elliptical): Shift + F4 to F6[cite: 10]
  • Line & Graphic Boxes: Shift + F7 to F10[cite: 10]

Learning Unit 2: Insert Images and Objects

  • Picture Boxes: Select a picture box tool (Rectangular, Elliptical, or Round Rectangular) and drag it across the document area[cite: 10].
  • Inserting Images: Double-click the picture box or go to File > Import Picture to browse and select the target image file[cite: 10].
  • Picture Adjustments: Using the I-Beam tool on a picture box, you can modify horizontal/vertical scaling, brightness, contrast, rotation angles, and center alignment via the object ribbon[cite: 10].

Learning Unit 3: Perform Formatting and Style Setting

  • Text Formatting: Modify font family (e.g., Noori Nastaliq for Urdu, Arial/Times New Roman for English), font size (in points), font color, style (Bold, Italic, Outline), and character scaling[cite: 10].
  • Paragraph Formatting: Adjust alignments (Right, Left, Center, Justified), line spacing (Line Height and Interline Gap), indents, and tab stops using the top Ribbon or Paragraph Preferences dialog[cite: 10].

Learning Unit 4: Print the Document

  • To print or convert an InPage document into a PDF file, go to File > Print[cite: 10].
  • In the printer selection menu, choose a physical printer for paper printing, or select Microsoft Print to PDF to export and save the document as a digital PDF file[cite: 10].
