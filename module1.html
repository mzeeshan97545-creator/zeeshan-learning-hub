Learning Unit 1: Install Operating System

Computer consists of two main parts: Hardware and Software. System software (Operating System) is the main software which controls and manages the computer and all attached devices.

Basic Parts & Components of Computer

  • CPU / System Unit: The brain of the computer containing Memory Unit (RAM & Secondary storage), Control Unit, and Arithmetic Logic Unit (ALU).
  • Input Unit: Devices used to give input like keyboard, mouse, and scanner.
  • Output Unit: Devices used to display output like monitor, printer, and speaker.

Windows 10 Clean Installation Steps

  1. Backup Data: Always backup your files to an external storage (USB/Hard Drive) using File Explorer (%HOMEPATH%).
  2. Boot Sequence Setting: Restart PC, enter BIOS/UEFI setup (F2, F10, Del) and set CD/DVD or USB as the first boot device.
  3. Run Setup: Insert Windows installation media, restart, press any key to boot from CD/DVD/USB.
  4. Language & Setup: Select language, click Install Now, and enter or skip product key.
  5. Choose Installation Type: Select Custom: Install Windows only (advanced) for a clean install.
  6. Partition & Install: Select unallocated space or partition, click Next, and let files copy. Complete regional preferences and user account setup.

Learning Unit 2: Install / Configure Peripheral Devices

Peripherals are auxiliary devices connected to a computer (keyboard, mouse, printer, scanner, webcam, joystick). They connect through various communication ports like USB, Serial, Parallel, Ethernet (RJ45), VGA, and PS/2 (Purple for keyboard, Green for mouse).

Learning Unit 3: Install Software Applications

Application software includes productivity tools like MS Office (Word, Excel, Access, PowerPoint). Installation can be Full/Typical (installs everything automatically) or Customized (allows user to choose specific components and paths).

Learning Unit 4 & 5: Update / Upgrade Drivers & Software

Use Device Manager (`devmgmt.msc`) to manage and update hardware drivers. Software updates enhance stability and features, while upgrades replace older versions with newer ones. Always create a System Restore Point before updating.

Learning Unit 6 & 7: Uninstallation & Windows Scan

Always uninstall programs properly via Control Panel's Programs and Features to clean up Windows Registry entries. Run full system scans using Windows Security or registered antivirus software (like Avast) to protect against malware and viruses.

Learning Unit 8, 9 & 10: Storage Formatting & Troubleshooting

External mass storage devices (USB flash drives, SD cards) can be formatted via My Computer by right-clicking and selecting Format (FAT32/NTFS). Software and hardware troubleshooting involves checking power cables, running Task Manager (`Ctrl + Alt + Delete`) for frozen apps, cleaning physical dust, and maintaining proper airflow.
