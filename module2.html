Module 02: Prepare MS Word Document

Learning Outcomes: After completion of this learning module, learners will be able to type documents, set up pages, edit and format documents, insert elements (tables, illustrations, headers/footers, table of contents), hyperlink data, and protect documents with passwords[cite: 6].

Learning Unit 1: Type Word Document

Word Processor: Software used to create, edit, format, and print text-based documents in different formats and styles (e.g., Microsoft Word, WordPad, WordStar, WordPerfect). Microsoft Word is the most popular word processor[cite: 6].

Microsoft Word 2016: Enhanced features include a customized Office Background, live OneDrive access, and resume-from-where-you-left-off capabilities[cite: 6].

Creating a New Document:

  1. Click the File menu/tab[cite: 6].
  2. In the Backstage View, click New[cite: 6].
  3. Press [Ctrl] + [N] (faster & easier way)[cite: 6].
  4. Click Blank Document[cite: 6].

Typing Using Different Keyboard Keys:

  • Alphanumeric Keys: Letter, number, and special character keys[cite: 6].
  • Control Keys: Used separately or in combination (e.g., Ctrl+S for save, Ctrl+O for open)[cite: 6].
  • Function Keys: F1 to F12 for specific programmatic tasks[cite: 6].
  • Navigation Keys: Arrow keys, Home, End, Page Up, Page Down, Delete, Insert[cite: 6].
  • Numeric Keypad: Calculator-style keys for fast number entry[cite: 6].

Spelling & Grammar Check:

Go to the Review tab and click Spelling & Grammar. Options include Ignore, Ignore All, Add to Dictionary, Change, and Change All[cite: 6].

Saving and OneDrive:

To save for the first time, go to File > Save As > This PC > Desktop or save directly to OneDrive for cloud backup and syncing[cite: 6].

Learning Unit 2: Set-Up Page in a Word Document

  • Orientation: Go to Page Layout > Orientation (Choose Portrait or Landscape)[cite: 6].
  • Margins: Go to Page Layout > Margins (Choose Normal, Narrow, Moderate, Wide, or Custom Margins)[cite: 6].
  • Paper Size: Go to Page Layout > Size (Choose Letter, Legal, A4, Executive, etc.)[cite: 6].
  • Columns: Select text, go to Page Layout > Columns (Choose One, Two, Three, Left, or Right)[cite: 6].
  • Section & Page Breaks: Use breaks to separate layout styles, change headers/footers per section, or restart page numbering. Types include Next Page, Continuous, Even Page, and Odd Page[cite: 6].
  • Headers & Footers: Double-click the top/bottom margin or use the Insert tab. Use options like "Different First Page" or "Different Odd & Even Pages"[cite: 6].

Learning Unit 3: Edit a Document

Editing commands are located in the Home tab (Clipboard and Editing groups)[cite: 6]:

  • Cut (Ctrl+X) & Copy (Ctrl+C): Places selected text onto the clipboard[cite: 6].
  • Paste (Ctrl+V): Inserts clipboard contents at the insertion point[cite: 6].
  • Find (Ctrl+F) & Replace (Ctrl+H): Searches for text or replaces words across the document using the Navigation pane[cite: 6].
  • Go To (Ctrl+G / F5): Quickly jumps to a specific page, section, or line[cite: 6].

Learning Unit 4: Format a Word Document

  • Character Formatting (Font Group): Adjust font face, size, bold (Ctrl+B), italic (Ctrl+I), underline (Ctrl+U), subscript, superscript, text highlight, and font color[cite: 6].
  • Paragraph Formatting (Paragraph Group): Alignment (Left, Center, Right, Justify), Line Spacing (1.0, 1.5, 2.0), Bullets, Numbering, and Indentation (First Line, Left, Right, Hanging Indents)[cite: 6].
  • Tab Stops: Set precise alignment points on the Ruler (Left, Right, Center, Decimal, Bar) and add dot/dash **Leaders** for tables of contents[cite: 6].

Learning Unit 5: Insert Elements in a Word Document

  • Pages Group: Insert Cover Page, Blank Page, or Page Break (Ctrl+Enter)[cite: 6].
  • Tables Group: Create tables by dragging, using the Insert Table dialog, drawing with a pencil tool, or inserting Quick Tables (calendars)[cite: 6]. Format via contextual Design and Layout tabs[cite: 6].
  • Illustrations Group: Insert Pictures, Online Pictures, Shapes, SmartArt, Charts, and Screenshots[cite: 6].
  • Links & Comments: Add Hyperlinks (Ctrl+K), Bookmarks, Cross-references, and Review Comments[cite: 6].
  • Text & Symbols: Text Boxes, WordArt, Drop Caps, Signature Lines, Date & Time, Equations, and Symbols[cite: 6].

Learning Unit 6: Insert Table of Contents & References

  • Table of Contents: Format document headings using Home tab styles, then go to References > Table of Contents[cite: 6].
  • Footnotes & Endnotes: Add bottom-of-page notes or document-end notes from the References tab[cite: 6].
  • Citations & Bibliography: Manage sources, insert citations, and generate automatic bibliographies[cite: 6].
  • Captions & Index: Add figure captions, build a Table of Figures, and mark index entries[cite: 6].

Learning Unit 7: Protect Document with Password

  • Restrict Formatting & Editing: Go to Review > Restrict Editing to limit styles, allow only comments/tracked changes, or set enforcement protection passwords[cite: 6].
  • Encrypt with Password: Go to File > Info > Protect Document > Encrypt with Password to secure your file[cite: 6].

Learning Unit 8: Print the File

  1. Go to File > Print (or press Ctrl+P)[cite: 6].
  2. Select your preferred printer from the dropdown menu[cite: 6].
  3. Adjust settings such as number of copies, page range, orientation (Portrait/Landscape), and paper size[cite: 6].
  4. Review the print preview and click Print[cite: 6].
