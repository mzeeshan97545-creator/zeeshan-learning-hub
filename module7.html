Module 07: Manage Email using Outlook

Learning Outcomes: After completion of this learning module, learners will be able to create and configure email accounts on MS Outlook, apply security and digital encryption, manage rules and spam, and execute email backup and restoration[cite: 11].

Learning Unit 1: Configure Email Account

Email: Stands for electronic mail. Used to send electronic messages over the internet using unique email addresses[cite: 11]. Accessed either via web browsers or desktop applications like Microsoft Outlook[cite: 11].

Configuring Email in MS Outlook 2016:

  • Auto Account Setup: Enter your Name, Email Address, and Password on the welcome screen for automatic server detection[cite: 11].
  • Manual Setup (POP3 / IMAP): If auto-setup fails, select manual setup and configure server settings[cite: 11].
    • Incoming Server Port: 995 for POP3 or 993 for IMAP (with SSL enabled)[cite: 11].
    • Outgoing Server (SMTP) Port: 465 (with SSL enabled and SMTP Authentication required)[cite: 11].

Outlook Interface Components:

  • Navigation Pane / Mail / Calendar / People / Tasks: Manage emails, schedule meetings, maintain contact lists, and track to-do lists[cite: 11].
  • Reading Pane & Folder Pane: Customize layouts (Right, Bottom, Off) and manage custom folder hierarchies[cite: 11].
  • Global Address List: Access directory contacts quickly by typing a name and pressing Ctrl + K[cite: 11].
  • Signatures: Create custom signatures for new messages and replies via Signatures and Stationery[cite: 11].

Learning Unit 2: Apply Security and Encryption

  • Junk Email Filters: Automatically sort, move, or block spam by configuring rules via Home > Rules > Manage Rules & Alerts[cite: 11].
  • Not Junk: Recover legitimate emails from the Junk folder by selecting Junk > Not Junk to move them to the inbox and whitelist the sender[cite: 11].
  • Digital Signatures: Ensure authenticity and integrity of outgoing messages[cite: 11]. Create self-signed certificates using SelfCert.exe located in the Office root folder (e.g., Office16) and enable signing in the Outlook Trust Center[cite: 11].

Learning Unit 3: Backup and Restore Mails

Outlook allows you to backup and archive emails into an Outlook Data File (.pst) for data security and migration[cite: 11].

  • Backing Up (Export): Go to File > Open & Export > Import/Export > Export to a file > Outlook Data File (.pst), select folders, and choose a destination path[cite: 11]. Default archive location: C:\Users\<username>\Documents\Outlook Files\archive.pst[cite: 11].
  • Restoring (Import): Use the Import/Export wizard selecting Import from another program or file to restore data from a .pst file back into Outlook[cite: 11].
