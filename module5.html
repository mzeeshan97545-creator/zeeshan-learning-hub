Module 05: Create Presentation in MS PowerPoint

Learning Outcomes: After completion of this learning module, learners will be able to create and manage slides, design presentations, define themes and their purpose, apply transitions, and configure animations and slide show settings[cite: 9].

Learning Unit 1: Create and Manage Slides

Microsoft PowerPoint 2016: A presentation software application used to create professional, high-impact, dynamic presentations using slides as building blocks[cite: 9].

Creating a New Presentation:

  • Click File > New > Blank Presentation (Shortcut: Ctrl + N)[cite: 9].
  • Adding Additional Slides: Click the top portion of the New Slide command on the Home tab, or use shortcut Ctrl + M[cite: 9].

Common Slide Layouts:

Layout NameDescription
Title SlideIncludes placeholders for a main title and subtitle[cite: 9].
Title and ContentIncludes placeholders for title, text, charts, tables, pictures, and SmartArt[cite: 9].
Section HeaderAllows space for section and sub-section titles[cite: 9].
Two Content / ComparisonContains two content boxes to compare and contrast data[cite: 9].
Blank / Title OnlyMinimalist layouts for custom objects or images[cite: 9].

Learning Unit 2: Design Presentation

Themes: A theme includes a background design, color scheme, font types, font sizes, and placeholder positions in one package[cite: 9]. The default starting theme is the Office Theme (white background, black text)[cite: 9].

  • Go to the Design tab on the Ribbon to browse and select thumbnails of different design themes[cite: 9].
  • Hovering over a theme gives a live preview before applying it to the presentation[cite: 9].

Learning Unit 3: Apply Animations and Slide Show Settings

Slide Transitions:

Animated effects applied when moving from one slide to the next during a slideshow[cite: 9].

  • Configured via the Transitions tab (e.g., Fade, Push, Wipe, Split, Uncover)[cite: 9].
  • Use Apply To All to apply the selected transition across the entire presentation[cite: 9].
  • Timing & Advance Slide: Set transitions to advance On Mouse Click or automatically After a specific time interval[cite: 9]. Sounds can also be added during transitions[cite: 9].

Slide Animations:

Animated effects applied to text and graphics within a slide (Entrance, Emphasis, Exit)[cite: 9].

  • Configured via the Animations tab[cite: 9].
  • Timing Group: Modify sequence, duration, delay, and start triggers (On Click, With Previous, After Previous)[cite: 9].
  • Animation Pane: Displays all applied animations on a slide for easy reordering and management[cite: 9].

Practical Learning Activity

Prepare a complete presentation by adding slides, selecting appropriate layouts, applying custom themes, configuring slide transitions and timing, and adding entrance/exit animations with customized durations[cite: 9].
