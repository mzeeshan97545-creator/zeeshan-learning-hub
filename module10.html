Module 10: Install and Configure Network Connections

Learning Outcomes: After completion of this learning module, learners will be able to select appropriate network cables (CAT5, CAT6, CAT7), differentiate between UTP and STP cables, prepare straight-through and crossover cables, perform network connectivity, configure wired and wireless NICs, and execute basic network troubleshooting using ping, traceroute, and cable testers[cite: 7].

Learning Unit 1: Prepare Network Cables

  • Networks & Topologies: Interconnection of computers to share data and resources (LAN, WAN). Physical arrangements include Bus, Star, and Ring topologies[cite: 7].
  • UTP vs. STP Cables: UTP (Unshielded Twisted Pair) is cost-effective and ideal for low-EMI environments like offices. STP (Shielded Twisted Pair) includes foil or braided shielding to protect against Electromagnetic Interference (EMI) and Radio Frequency Interference (RFI) in industrial settings[cite: 7].
  • Cable Standards & Wiring:
    • Straight-Through Cable: Both ends use the same standard (T-568A or T-568B). Used to connect dissimilar devices (e.g., PC to Switch/Router)[cite: 7].
    • Crossover Cable: One end uses T-568A and the other uses T-568B. Used to connect similar devices directly (e.g., PC to PC)[cite: 7].
  • Network Cable Categories: CAT5 (100 MHz, up to 100 Mbps), CAT5e (100 MHz, 1 Gbps), CAT6 (250 MHz, up to 10 Gbps at short distances), CAT6a (500 MHz, 10 Gbps up to 100m), CAT7/CAT7a (600–1000 MHz, shielded S/FTP for high-performance data centers)[cite: 7].
  • Tools Required: Cable crimper, wire stripper, cable cutter, RJ-45 connectors, and cable tester[cite: 7].

Learning Unit 2: Perform Network Connectivity

  • Network Interface Cards (NIC): Hardware components enabling network connection (Wired Ethernet, Wireless Wi-Fi, USB, and Fiber Optic NICs)[cite: 7].
  • IP Configuration: Automatic configuration via DHCP or manual setup by entering a unique IP Address (e.g., 192.168.1.101), Subnet Mask (255.255.255.0), and Default Gateway[cite: 7].
  • Wireless LAN (WLAN): Adapters connect devices to wireless networks via radio waves using SSID and security keys/passwords[cite: 7].
  • Diagnostic Commands:
    • ping [IP/Domain]: Tests device reachability and measures latency via ICMP echo requests[cite: 7].
    • tracert [IP/Domain] (Windows) / traceroute (Linux/Mac): Traces the path (routers/hops) packets take to reach a destination[cite: 7].

Learning Unit 3: Perform Basic Network Troubleshooting

  • Cable Tester: Checks physical and electrical integrity, continuity testing, wiremap configuration, and fault detection (shorts, opens, miswires)[cite: 7].
  • Identifying Faulty Cables: Use visual inspection (cuts, frayed wires, damaged RJ45 pins), test with another port/device, or use cable testers[cite: 7].
  • Speed Test Tools: Use tools like Speedtest by Ookla, Fast.com, or Google PageSpeed Insights to measure Download speed, Upload speed, Ping/Latency, and Jitter[cite: 7].
