Module 03: Prepare Spreadsheet

Learning Outcomes: After completion of this learning module, learners will be able to create workbooks, enter and format data, apply mathematical formulas and functions, manage page layouts, insert charts, and use advanced tools like sparklines[cite: 7].

Learning Unit 1: Create Workbook

Spreadsheet: An interactive computer application used for organizing, analyzing, manipulating, and storing data in tables (rows and columns). Its unique feature is the ability to calculate values using formulas[cite: 7].

Types of Spreadsheets:

  • Two-Dimensional Spreadsheets: Cells arranged in standard rows and columns[cite: 7].
  • Three-Dimensional Spreadsheets: Multiple sheets stacked on top of each other[cite: 7].
  • Arithmetic & Logical Spreadsheets: Used for automated calculations/budgets or deductive/inductive reasoning[cite: 7].

Excel 2016 Interface Components:

  • Worksheet / Workbook: A workbook contains multiple worksheets (Default name: Book1). Total rows: 1,048,576; Total columns: 16,384 (XFD)[cite: 7].
  • Cell & Cell Reference: Intersection of a column and row (e.g., cell address C5)[cite: 7].
  • Formula Bar & Name Box: Displays active cell reference and formula/content entry area[cite: 7].

Creating a New Workbook:

  1. Click the File tab > New > Blank Workbook[cite: 7].
  2. Or simply press [Ctrl] + [N][cite: 7].

Protection & Security:

Protecting workbooks/worksheets prevents unauthorized changes, maintains data integrity, protects formulas, controls access, and secures sensitive info[cite: 7].

Learning Unit 2: Enter and Format Data in Cell

  • Entering Text: Select cell, press F2 or type directly. Press [Alt] + [Enter] to wrap text inside a cell manually[cite: 7].
  • Merge & Center: Select cells and click Merge & Center in the Home tab[cite: 7].
  • Conditional Formatting: Highlights cells automatically based on specific criteria (e.g., greater than a set number, top/bottom rules, data bars, icon sets)[cite: 7].

Learning Unit 3: Apply Different Mathematical Formulas / Functions

Formula vs Function: A formula is written and calculated by the user (e.g., =B4*C4), while a function is a built-in pre-defined code (e.g., =SUM(F4:G4))[cite: 7]. All formulas must start with an equals sign (=)[cite: 7].

Operator Precedence:

  1. Percent (%)[cite: 7]
  2. Exponent (^)[cite: 7]
  3. Multiplication (*) & Division (/)[cite: 7]
  4. Addition (+) & Subtraction (-)[cite: 7]
  5. Logical Operators (<, >, =, <=, >=, <>)[cite: 7]
  6. Parenthesis ( ) (Highest priority)[cite: 7]

Commonly Used Excel Functions:

FunctionSyntax / ExamplePurpose
SUM=SUM(range)Adds numbers in a range[cite: 7]
AVERAGE=AVERAGE(range)Calculates arithmetic mean[cite: 7]

XLOOKUP=XLOOKUP(val, lookup_arr, return_arr)Modern, flexible lookup function[cite: 7]
SUMPRODUCT=SUMPRODUCT(range1, range2)Conditional sum with multiple logic criteria[cite: 7]

Learning Unit 4: Apply Page Layout Setting

  • Themes: Go to Page Layout > Themes to quickly apply professional color palettes, fonts, and visual effects[cite: 7].
  • Page Setup Options: Customize margins, orientation (Portrait/Landscape), paper size (Letter, Legal, A4), scaling ("Fit to 1 page wide"), print area, and print titles[cite: 7].
  • Backgrounds: Insert background images or change individual cell fill colors using the Home tab[cite: 7].

Learning Unit 5: Create Charts / Graphs & Sparklines

  • Charts: Graphical representation of numeric data (Column, Line, Pie, Bar charts)[cite: 7]. Consists of a Chart Title, Horizontal/Vertical Axes, Data Series, and Legends[cite: 7]. Created via Insert > Charts[cite: 7].
  • Sparklines: Mini-charts placed inside a single cell to show data trends across rows (Line, Column, Win/Loss sparklines)[cite: 7].
