Module 11: Install and Configure Network Devices

Learning Outcomes: After completion of this learning module, learners will be able to install and connect network devices, configure IP classes and addresses, set up dynamic routing protocols (RIP, OSPF, EIGRP, BGP), bridge WLAN with LAN, manage duplex settings, and perform network maintenance, troubleshooting, and IP scanning[cite: 8].

Learning Unit 1: Install and Connect Network Devices

  • Network Types & Topologies: PAN, LAN, MAN, WAN, and WLAN[cite: 8]. Topologies include Bus, Star, Ring, Mesh, Tree, and Hybrid[cite: 8].
  • Network Media: Coaxial cables (RG-59, RG-6), Twisted Pair (UTP/STP), and Fiber Optic cables (Single-mode for long distance, Multi-mode for short distance)[cite: 8].
  • Device Placement: Position routers centrally and elevated; use switches to expand wired ports using Ethernet links[cite: 8].

Learning Unit 2: Configure IP Addresses of Hosts and Intermediary Devices

  • IP Address Classes:
    • Class A: Range 1.0.0.0 – 126.255.255.255 (Default Subnet: 255.0.0.0)[cite: 8]. Loopback: 127.0.0.1[cite: 8].
    • Class B: Range 128.0.0.0 – 191.255.255.255 (Default Subnet: 255.255.0.0)[cite: 8].
    • Class C: Range 192.0.0.0 – 223.255.255.255 (Default Subnet: 255.255.255.0)[cite: 8].
    • Class D: Range 224.0.0.0 – 239.255.255.255 (Multicast)[cite: 8].
    • Class E: Range 240.0.0.0 – 255.255.255.255 (Experimental)[cite: 8].
  • Allocation Methods: Static IP (manual setup for servers/printers) vs. Dynamic IP (automatic via DHCP servers)[cite: 8].

Learning Unit 3: Configure Dynamic Routing Protocols

  • Routing Protocols Overview: Automatically adjust paths using algorithms[cite: 8]. Divided into IGPs (Interior Gateway Protocols like RIP, OSPF, EIGRP) and EGPs (Exterior Gateway Protocols like BGP)[cite: 8].
  • Protocol Configurations:
    • RIP (Routing Information Protocol): Distance-vector protocol using hop counts (max 15 hops); configure via router rip and version 2[cite: 8].
    • OSPF (Open Shortest Path First): Link-state protocol using cost metrics and Area 0 backbone; configure via router ospf 1 and wildcard masks[cite: 8].
    • EIGRP (Enhanced Interior Gateway Routing Protocol): Hybrid protocol using DUAL algorithm; configure via router eigrp [AS-number][cite: 8].
    • BGP (Border Gateway Protocol): Inter-AS routing protocol requiring manual neighbor mapping via neighbor [IP] remote-as [AS][cite: 8].
  • Convergence: The state where all routers synchronize on best paths after a topology change (OSPF/EIGRP converge fast; RIP/BGP converge slower)[cite: 8].

Learning Unit 4: Perform Maintenance & Troubleshooting

  • Diagnostic Tools: ping (tests reachability and RTT), tracert / traceroute (tracks packet hops), ipconfig / ifconfig, nslookup (DNS checks), and netstat[cite: 8].
  • Duplex Settings: Half-duplex (one direction at a time, prone to collisions) vs. Full-duplex (simultaneous transmission, no collisions). Auto-negotiation prevents duplex mismatch issues[cite: 8].
  • Common Problems: IP address conflicts, DNS resolution failures, and physical hardware malfunctions[cite: 8].
  • WLAN Bridging & AP Setup: Configuring Access Point / Bridge modes, disabling secondary DHCP servers, and avoiding channel interference[cite: 8].
  • IP Scanning Tools: Using tools like Nmap, Angry IP Scanner, Advanced IP Scanner, and Fing to discover active devices, open ports, and map subnets[cite: 8].
