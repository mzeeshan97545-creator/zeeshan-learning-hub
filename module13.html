Module 13: Get Started with C#

Learning Outcomes: After completion of this learning module, learners will be able to download and install Visual Studio Community Edition, create C# projects, write basic programs, declare variables and constants, use operators, implement implicit and explicit type conversions, compile and run programs, and manage console I/O using format specifiers and string concatenation[cite: 8].

Learning Unit 1: Install Microsoft Visual Studio

  • Visual Studio Community Edition: A free, full-featured IDE for individual developers, open-source projects, and education with complete support for C# and .NET[cite: 8].
  • Installation Requirements: Windows 10/11 (64-bit), 1.8 GHz quad-core processor recommended, 4 GB RAM minimum (8 GB+ recommended), and an SSD with adequate space[cite: 8]. Select the .NET desktop development workload during installation[cite: 8].
  • Key IDE Elements: Solution Explorer, Code Editor, Toolbox, Properties Window, Output Window, Error List, and Debug Toolbar[cite: 8].

Learning Unit 2: Utilize Primitive Data Types and Variables in Practice

  • Project Types: Supports Console Applications, Windows Forms, WPF, ASP.NET Web Apps, Class Libraries, and Unit Test Projects[cite: 8].
  • Basic Structure of a C# Program: Includes using directives (using System;), namespaces, classes, the entry point method (static void Main(string[] args)), and statements ending with a semicolon[cite: 8].
  • Variables & Constants: Variables (e.g., int age = 25;) hold changing values[cite: 8]. Constants (e.g., const double Pi = 3.14159;) use the const keyword and cannot be modified after declaration[cite: 8].
  • Operators: Arithmetic (+, -, *, /, %), Comparison (==, !=, >, <), Logical (&&, ||, !), Assignment (=, +=, -=), and Unary/Ternary operators[cite: 8].
  • Type Conversions:
    • Implicit Conversion: Automatically done by the compiler when safe (e.g., int to double)[cite: 8].
    • Explicit Conversion (Casting): Manually specified when precision loss or overflow might occur (e.g., (int)myDouble)[cite: 8].
  • Compilation & Execution: Compiling translates C# source code into Intermediate Language (IL), which is executed by the Common Language Runtime (CLR) via Visual Studio or the .NET CLI (dotnet run)[cite: 8].

Learning Unit 3: Interact with Console for I/O

  • Console I/O Methods: Console.Write() prints text on the same line; Console.WriteLine() appends a newline; Console.ReadLine() reads user input as a string[cite: 8]. Input conversion is done using methods like Convert.ToInt32()[cite: 8].
  • Format Specifiers: Control display formatting for numbers, currency (C), fixed-point decimals (F2), percentages (P), and dates using placeholders (e.g., {0:C} or string interpolation {val:C})[cite: 8]. Alignment can be managed via field widths (e.g., {0,-10})[cite: 8].
  • String Concatenation: Combining strings using the + operator, string interpolation ($"..."), or utility methods like String.Concat() and String.Join()[cite: 8].
