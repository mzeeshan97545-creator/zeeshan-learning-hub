Module 15: Manage Flow Control using Conditional Statement & Loops

Learning Outcomes: After completion of this learning module, learners will be able to implement if, else-if, switch, and nested conditional statements, as well as repetition structures including while, do-while, for loops, and nested loops in C#[cite: 8].

Learning Unit 1: Manage Flow Control with Conditional Statement

  • If & If-Else Statements: Evaluates boolean expressions to direct program flow. Executes code blocks conditionally based on whether the evaluated expression is true or false[cite: 8].
  • If-Else-If Ladder: Evaluates multiple sequential conditions in order (e.g., grading systems based on scores) until a matching condition is found[cite: 8].
  • Switch Statements: Efficiently maps a single variable or expression against multiple discrete constant cases using case, break, and default keywords[cite: 8].
  • Nested If Statements: Places conditional statements inside other conditional blocks to handle complex, hierarchical decision-making processes[cite: 8].

Learning Unit 2: Apply Loop Structures

  • While Loop: Pre-test loop that repeatedly executes a block of code as long as the specified condition evaluates to true[cite: 8].
  • Do-While Loop: Post-test loop that guarantees the code block executes at least once before checking the condition at the end[cite: 8].
  • For Loop: Entry-controlled loop used for executing statements a specific, known number of times using initialization, condition, and iteration statements (e.g., for (int i = 0; i < 5; i++))[cite: 8].
  • Nested Loops: Placing one loop inside another (e.g., an inner loop running completely for each single iteration of the outer loop), ideal for matrices, tables, and multi-dimensional tracking[cite: 8].
