Module 17: Implement Methods in OOP

Learning Outcomes: After completion of this learning module, learners will be able to create and call methods with parameters and return values, implement Object-Oriented Programming (OOP) classes, configure getters/setters and access modifiers, and utilize default and parameterized constructors in C#[cite: 8].

Learning Unit 1: Implement Methods in Program

  • Methods Overview: A block of code executed only when called, used to promote code reuse and modularity (functions)[cite: 8].
  • Parameters & Arguments: Data passed into methods to customize behavior, supporting multiple parameters and default parameter values (e.g., string country = "Pakistan")[cite: 8].
  • Return Values: Using primitive data types (like int or double) instead of void alongside the return keyword to output processed results[cite: 8].

Learning Unit 2: Implement Class

  • OOP Concepts: Object-Oriented Programming structures programs around objects containing data fields and methods, providing cleaner structure, reusability, and maintenance compared to procedural programming[cite: 8].
  • Classes & Objects: A class acts as a template, while an object is an instance of a class created using the new keyword[cite: 8].
  • Getters & Setters: Methods or auto-implemented properties ({ get; set; }) used to securely control access, validation, and modification of private class fields[cite: 8].
  • Access Modifiers: Define visibility using public (accessible everywhere), private (accessible within the same class only), protected, and internal[cite: 8].

Learning Unit 3: Implement Constructors in a Class

  • Constructors Overview: A special method that automatically runs when an object of a class is created, used to initialize object fields[cite: 8]. Must match the class name and have no return type[cite: 8].
  • Parameterless / Default Constructors: Automatically generated by C# if not explicitly written, setting default or uninitialized values[cite: 8].
  • Parameterized Constructors: Accept arguments during object creation to assign custom initial values to class variables (e.g., public Car(string modelName))[cite: 8].
