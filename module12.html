Module 12: Install and Configure Network Utilities Software

Learning Outcomes: After completion of this learning module, learners will be able to download, install, and configure utility software, update software versions and patches, install device drivers, and download, install, or update firmware for network devices[cite: 7].

Learning Unit 1: Install and Configure Utility Software

  • System Requirements: Assessing hardware and software specifications (OS compatibility, CPU, RAM, disk space, network requirements, and dependencies) to avoid compatibility or performance issues[cite: 7].
  • Official Sources: Always download utility software (like Wireshark, Nmap, Advanced IP Scanner) from official websites to ensure security, reliability, and proper licensing[cite: 7].
  • Integrity Verification: Checking digital signatures and comparing hash values (e.g., SHA-256 checksums using certutil -hashfile filename.exe SHA256 on Windows) to confirm file authenticity[cite: 7].
  • Software Wizard & Installation Options: Using guided setup wizards, choosing between Typical vs. Custom installations, and selecting 32-bit (x86) or 64-bit (x64) architectures based on system specifications[cite: 7].
  • Launching Software: Opening applications via desktop shortcuts, start menus, or command-line interfaces with administrative privileges when required[cite: 7].

Learning Unit 2: Install Device Drivers

  • Device Compatibility: Ensuring utility software and drivers communicate correctly with underlying hardware components, NICs, and operating system platforms (Windows, macOS, Linux)[cite: 7].
  • Installation & Troubleshooting: Step-by-step installation procedures, running installers as administrator, addressing permission errors, resolving installation freezes, and updating missing dependencies[cite: 7].

Learning Unit 3: Install/Update Firmware

  • What is Firmware? Low-level embedded software stored in non-volatile memory that controls hardware device operations (routers, printers, motherboards/BIOS, and smartphones)[cite: 7].
  • Verifying Current Version: Checking device version numbers via router web interfaces (e.g., 192.168.1.1), BIOS setup screens, or command-line utilities (e.g., wmic bios get smbiosbiosversion)[cite: 7].
  • Researching & Downloading Updates: Visiting manufacturer support pages (e.g., TP-Link, ASUS, HP) to locate exact model numbers, hardware revisions, and release notes[cite: 7].
  • Data Backup: Backing up configurations, export settings, and critical user data before running firmware updates to prevent data loss or device bricking[cite: 7].
