Module 04: Create Basic Database using MS Access

Learning Outcomes: After completion of this learning module, learners will be able to create databases in MS Access, establish relationships between tables, design forms, and create queries and reports[cite: 8].

Learning Unit 1: Create Database in MS Access

Database: An organized collection of related data stored in an efficient and compact manner[cite: 8].

DBMS: A software system that enables users to define, create, and maintain a database (e.g., MS Access, SQL Server, Oracle, MySQL)[cite: 8]. MS Access saves files with a .accdb extension[cite: 8].

Core Database Objects in MS Access:

  • Tables: Define and store data in rows (records) and columns (fields)[cite: 8].
  • Queries: Retrieve, filter, or manipulate data[cite: 8].
  • Forms: User interfaces to enter, view, or edit data[cite: 8].
  • Reports: Formatted, printable summaries of data[cite: 8].
  • Macros & Modules: Used for automation and advanced programming[cite: 8].

Database Keys:

  • Primary Key: A candidate key uniquely identifying each record in a table (must exist, be unique, and not change over time)[cite: 8].
  • Foreign Key: A primary key from one table that appears as a field in another table to create a relationship[cite: 8].
  • Composite Key: A key consisting of two or more attributes that uniquely identify a record[cite: 8].

Learning Unit 2: Establish Relationships Between Tables

A relationship is a logical connection between tables defining how data relates[cite: 8].

  • One-to-One (1:1): Each record in Table A relates to only one record in Table B[cite: 8].
  • One-to-Many (1:N): A record in Table A relates to multiple records in Table B (denoted by 1 and ∞ symbols when Referential Integrity is enforced)[cite: 8].
  • Many-to-Many (M:N): Implemented using a third junction/linking table containing foreign keys from both tables[cite: 8].

Learning Unit 3: Create Forms

A form is a database object used to enter, display, or edit data in a user-friendly interface[cite: 8].

  • Form Views: Form View, Layout View, Design View, Single Form, Continuous Forms, and Split Form[cite: 8].
  • Controls: Bound controls (linked to a table/query field) and Unbound controls (labels, images, logos)[cite: 8].

Learning Unit 4: Create Query and Report

Queries: Requests for data results or actions[cite: 8]. Types include Select Queries and Action Queries (Make Table, Append, Update, and Delete queries)[cite: 8]. Wildcards like *, ?, and [] are used in criteria definitions[cite: 8].

Reports: Designed to present data in a formatted, printable output for summarizing and analyzing data professionally[cite: 8]. Sections include Page Header, Detail, and Page Footer[cite: 8].

Calculations & Expressions in Access:

  • Total Marks: TotalMark: [Math_Obt] + [Urdu_Obt] + [Islamic_stu] + [Pak_Stu][cite: 8]
  • Average & Percentage: Average: [TotalMark] / 4 and percentage calculations[cite: 8]
  • Nested IF for Grades: Grade: IIf([percen]>90, "A", IIf([Per] > 80, "B", ...))[cite: 8]

Practical Project Summary: Student Information System

The module concludes with a comprehensive project requiring students to build a full MS Access database system featuring structured tables (Students, Courses, Enrollments, Grades, Attendance, Teachers), data entry forms, 5+ analytical queries, 3+ professional reports, and automated logic[cite: 8].
