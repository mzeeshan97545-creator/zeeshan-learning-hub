Module 09: Browse Internet and Manage Emails

Learning Outcomes: After completion of this learning module, learners will be able to perform internet browsing using different search engines, download and upload files securely, create email accounts, send/receive emails with attachments, manage spam, and utilize AI tools for email management[cite: 8].

Learning Unit 1: Perform Browsing

Search Engines: Software programs (e.g., Google, Bing, Yahoo) designed to search for information on the World Wide Web using robots/spiders, databases, and indexes[cite: 8].

Browsing Specific Objects & File Formats:

  • Advanced Searching (.ppt): To search for PowerPoint presentations, append file extensions to your keywords (e.g., parts of computer.ppt)[cite: 8].
  • Common Download Formats: .EXE (Executable), .PDF (Portable Document Format), .RAR / .ZIP (Compressed), .DOCX (Word Document)[cite: 8].
  • Precautions for Downloading: Download only from trusted sites (like CNET), save files to your hard disk before running them to let security software scan them, and avoid illegal downloads of copyrighted material[cite: 8].

Learning Unit 2: Create Email Account

  • Web-based Email: Allows users to access mail from any browser worldwide by signing in with a username and password[cite: 8].
  • Creating a Gmail Account: Navigate to www.gmail.com, select Create account > For myself, fill in personal information, choose a unique username and strong password, and complete phone/email verification[cite: 8].

Learning Unit 3: Send/Receive Emails

  • Composing & Sending: Click the Compose button, add recipient addresses in the To/Cc/Bcc fields, type a subject and message body, attach files using the paperclip icon, and click Send[cite: 8].
  • Signatures: Configure custom email signatures via Settings > See All Settings > Signature[cite: 8].
  • Spam Management: Report unwanted emails as spam, block senders, set up filtering rules, and manage blocked addresses via settings[cite: 8].
  • AI Tools in Email Management: Utilize built-in features like Smart Reply, Smart Compose, and "Help me write", or third-party AI extensions (e.g., Mailbutler, Compose AI, ChatGPT) for efficient drafting, summarization, and workflow automation[cite: 8].
