Module 16: Managing Arrays and Lists

Learning Outcomes: After completion of this learning module, learners will be able to declare, initialize, and manipulate 1-D and multi-dimensional arrays, use non-generic collections like ArrayList and Hashtable, and implement modern generic collections like List<T> and Dictionary<TKey, TValue> in C#[cite: 7].

Learning Unit 1: Utilizing Arrays in C# Program

  • Arrays Overview: A collection of continuous memory locations storing elements of the same data type, accessed via zero-based indexing (from 0 to size - 1)[cite: 7].
  • Initialization & Access: Arrays can be initialized at declaration (e.g., string[] cars = {"Volvo", "BMW"};) or later using the new keyword[cite: 7]. Elements are processed efficiently using for or foreach loops[cite: 7].
  • Operations: Includes searching via Array.IndexOf(), sorting via Array.Sort(), updating elements by index, and handling multi-dimensional (2-D) matrices[cite: 7].

Learning Unit 2: Utilize Non-Generic Collections in C# Program

  • Non-Generic Collections: Part of System.Collections namespace, storing items as type Object without compile-time type safety[cite: 7].
  • ArrayList: Dynamically resizable list storing mixed data types, supporting Add(), Remove(), RemoveAt(), and Clear() methods[cite: 7].
  • Hashtable: Stores key-value pairs using hash codes for rapid lookup via unique keys, iterated using DictionaryEntry inside foreach loops[cite: 7].

Learning Unit 3: Utilize Generic Collections in C# Program

  • List<T>: A type-safe, generic collection part of System.Collections.Generic that supports dynamic resizing, sorting, indexing, and methods like Add(), Insert(), and Remove()[cite: 7].
  • Dictionary<TKey, TValue>: Stores unique key-value pairs providing high-performance lookups, updates, and key-based removal, processed easily using KeyValuePair<TKey, TValue> loops[cite: 7].
